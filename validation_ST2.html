Splash Screen validation report

The Splash Screen (splash.html) was validated using the W3C Markup Validation Service and passed with no errors. No structural or syntax errors were present, confirming that the page uses valid HTML5 with correctly nested elements and well-formed metadata throughout.

Action Impact Simulator (AIS) validation report

The Action Impact Simulator (ais.html) was validated using the W3C Markup Validation Service and passed with no errors.
